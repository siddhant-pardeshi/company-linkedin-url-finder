# Local context

This folder is the project’s local working context: the verified references, the decisions behind the build, and the evidence that the build works. It is intentionally inside the repository so the owner can audit how the result was produced.

- [RESEARCH.md](RESEARCH.md) — official documentation checked before implementation.
- [DECISIONS.md](DECISIONS.md) — architecture and accuracy decisions, including rejected alternatives.
- [VERIFICATION.md](VERIFICATION.md) — commands, test results, browser smoke evidence, package hashes, and sync status.
- `../../docs/assets/` — sanitized product screenshots used by the README.

Status at build time: local build complete and verified; GitHub publication and store submission are owner actions that have **not** been performed. See `VERIFICATION.md`.
